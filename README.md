# 出海企业落地里程碑

追踪人工智能企业与东盟伙伴从合作意向到本地试点和合同。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括人工智能企业、东盟本地合作伙伴、活动运营机构、市场准入顾问。

资料所依据的领域事实如下：

- 榜单按六类应用场景遴选企业
- 活动帮助企业对接多个东盟国家商业代表
- 现场形成多项初步合作意向并建议优先考察部分市场
- 进展按企业与目标国家分别记录，企业可同时推进多个国家
- 每个企业-国家组合记录产品能力、适用场景、合作方尽调、试点协议、数据使用范围、本地化事项、监管前置条件、里程碑证据和商业转化
- 新马泰等市场在数据许可、本地伙伴、试点场地和验收口径上各不相同
- 主办方从初步意向一直追踪到试点、验收和正式合同

资料同时约定：同一试点成果不得在不同国家重复申报；合作方更换、范围缩减、试点暂停、验收争议和意向失效均须记录原因；企业仅分享获授权的进度材料，当地伙伴确认自身责任；需区分尚待解决的市场准入问题与单纯没有跟进。

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
